\projectheading
  {基于 PatchX-MLP 的 SCR 入口 NOx 浓度预测}
  {2025.03--2025.08}

\begin{itemize}
  \item \textbf{项目简介：}
  融合多变量工业运行数据预测 SCR 入口 NOx 浓度，
  为脱硝过程运行优化提供依据。
  \item \textbf{技术栈：}
  Python、PyTorch、MLP、多尺度 Patch、时序分解、时频域联合损失。
  \item \textbf{模型设计：}
  结合多尺度 Patch 与趋势、季节项分解，
  通过 MLP 建模 Patch 内、Patch 间及变量间交互，
  融合局部变化、长期趋势与变量关联。
  \item \textbf{训练与验证：}
  完成时频域联合优化及消融实验；
  工业数据 96 步预测的 MSE/MAE 为
  \textbf{0.228/0.223}，
  较 TimeMixer 分别降低 \textbf{6.6\%/5.5\%}。
\end{itemize}

\projectheading
  {基于大模型的工作票智能生成系统}
  {2025.09--2026.09}

\begin{itemize}
  \item \textbf{项目简介：}
  面向电气检修任务，编排图纸解析、知识检索、生成与校验流程，
  辅助生成工作票中的工作内容及安全措施。
  \item \textbf{技术栈：}
  Python、Dify、LLM Agent、Tool Calling、
  VL Embedding、SAM、OCR、GraphRAG。
  \item \textbf{图纸抽取：}
  利用视觉特征匹配图例与多尺度图块，
  结合 SAM 分割、OCR 及位置约束，
  提取设备类别、位置和编号。
  \item \textbf{检索与编排：}
  结合实体关系检索与语义召回，关联设备、检修任务、
  安规条款及历史工作票；封装解析与检索工具，
  基于来源证据和模板生成内容，设置字段完整性、
  设备一致性检查及人工复核。
  \item \textbf{SFT 适配方案：}
  设计历史工作票指令样本与 LoRA 微调方案，
  以“检修任务＋检索证据”为输入、票面字段为输出，
  规划术语一致性、字段完整性及证据符合性评估。
\end{itemize}

\projectheading
  {大模型话题与安全检测系统}
  {2026.08--2026.10}

\begin{itemize}
  \item \textbf{项目简介：}
  构建文本与多语种音频检测模块，
  识别业务话题、提示词注入及有害内容，
  为模型调用提供风险判断与路由依据。
  \item \textbf{技术栈：}
  Python、PyTorch、Transformers、预训练编码器、
  多任务学习、FastAPI、SFT、LoRA、CosyVoice。
  \item \textbf{文本检测：}
  基于预训练编码器构建话题、攻击及有害内容分类头，
  通过掩码损失利用多来源数据的部分标签；
  完成数据清洗、去重与数据集划分，
  按误报约束校准阈值，结合白名单制定放行、拒答和复核策略。
  \item \textbf{音频检测：}
  对 Qwen2.5-Omni-3B 进行 SFT，
  检测多语种输入音频的有害内容及提示词注入、
  输出音频的有害内容；
  通过 TTS、CosyVoice 合成样本并添加噪声进行数据增强。
  \item \textbf{工程实现：}
  封装训练、评估与推理流程，
  提供文本检测接口，返回类别、分数和触发原因，
  对低置信度或检测能力缺失的请求设置复核分支。
\end{itemize}
