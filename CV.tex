\section{\makebox[\widthof{\faUsers}][c]{\color{CVBlue}\faUsers}\ 项目经历}
\projectheading
  {}
  {}
  {基于 Mask R-CNN 的地下管廊渗水检测}
在树莓派 Linux 环境下接入相机，搭建图像采集与 Mask R-CNN 本地推理原型，
通过检测框定位渗水区域，用像素级掩膜保留不规则的湿痕边界。
模型实验使用管廊现场图像，基于 COCO 预训练权重迁移学习，
针对渗水类别重训分类、边框回归和掩膜分支。
用 Swin Transformer 替换 ResNet 骨干以融合跨窗口特征，并在掩膜分支引入 PointRend，
细化边界处的不确定像素。模型消融实验中，AP 从 0.394 提升至 0.753，IoU 从 0.544 提升至 0.801。
系统方案使用 WebSocket 将分割结果回传至 PyQt5 客户端，在原图上叠加掩膜展示渗水位置，
记录检测时间和掩膜面积，支持按时间查询和导出历史记录。

\projectheading
  {}
  {}
  {基于 STM32 的多传感器环境监测终端}
在 STM32 上用 C 实现多传感器轮询，通过 I2C 总线按器件地址依次读取光照和温度数据，并解析各传感器的读数。
在采集原型基础上，固件设计按通道配置采样周期与转换等待时间，由定时状态机分开调度转换与读取，
各通道独立处理超时重试，并保留最近有效读数和异常状态。
无线链路采用 LoRa 点对点通信，与采样分开调度，定期上报节点编号、报文序号、光照、温度及通道状态。
接收端按节点汇总数据，通过报文序号识别丢包，并标记出现采样超时的通道。

\projectheading
  {}
  {}
  {ROS 2 驱动的自动购物机器人设计}
装置面向模拟超市的清单取货场景，采用固定相机与两排三列货架。树莓派在 Linux 下用 OpenCV 采集货架图像，
通过 YOLOv5 识别罐装饮料等商品，根据检测框更新货位表。同一货位连续两帧识别为清单中的目标后，
树莓派通过串口下发任务号和货位号，减少单帧误检触发的取货动作。
STM32 按各货位预先示教的关节角度，用定时器 PWM 控制四轴机械臂及夹爪完成接近、夹取、抬升和投放，随后回传任务状态。
树莓派结合原货位复拍和篮口光电开关的落料信号核对取货结果，确认后才扣减清单数量。
STM32 按任务号过滤重复指令。缺货或落料未确认时，树莓派记录对应货位并暂停任务。
